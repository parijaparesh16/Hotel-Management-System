---------------------------------------------------------
PROJECT DESCRIPTION
---------------------------------------------------------

The Hotel Management System is a desktop application developed
using Python and Tkinter to simplify hotel operations. The
application allows hotel staff to manage customer details,
room bookings, and hotel records through an easy-to-use
graphical interface.

The project helps reduce manual paperwork while improving
accuracy, efficiency, and customer service.

---------------------------------------------------------
FEATURES
---------------------------------------------------------

• User Login System
• Customer Management
• Room Booking Management
• Hotel Dashboard
• Add, Update, Delete Customer Records
• Store Customer Details in MySQL Database
• Simple and User-Friendly GUI
• Image-based Interface using Pillow

---------------------------------------------------------
INSTALLATION
---------------------------------------------------------

1. Install Python.
2. Install MySQL Server.
3. Install the required libraries:

   pip install pillow
   pip install mysql-connector-python

4. Create the required MySQL database.
5. Update the database username and password in the Python files.
6. Run:

   python login.py
